# 项目图标素材

`source.png` 为用户于 2026-10-27 指定的项目图标原图，按原字节保留。

当前转换仅改变尺寸/文件格式，不裁剪、不重绘、不移除底部文字。
`tools/distribution/make_icons.py` 使用 Pillow 确定性生成网页 PNG 和 Windows 多尺寸 ICO。

输出在 `apps/api/agenthub_rt/static/brand/`。ICO 包含 16、24、32、48、64、128、256 像素图像；
应用 exe、安装器、卸载器和开始菜单快捷方式统一使用它。网页会话、设置、控制台和 README 使用相同图案。

原始大图不进入安装包；只分发生成的图标资源。替换素材时先确认用户提供的源文件，再运行转换和发行构建。
