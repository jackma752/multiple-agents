1. 工作区

工作区路径与权限会显示在调用卡并纳入审批。文件引用仅能读取这个目录。Claude 当前是无内置工具的受限通道；DeepSeek 不具备本机文件工具，两者可使用你明确添加的文件片段。
怎样让 Agent 真正做项目
  • Codex：选择项目文件夹。只读可检查、解释；允许写入才可创建和修改项目文件。
  • 工具卡或自动阶段规则：决定需要批准的具体操作。命令前缀留空时，请求批准的命令会被自动拒绝；文件变更需要另勾选。工作区可写不代表已批准任意命令。
  • Claude Code：当前接入关闭原生文件工具；DeepSeek：API 没有本机文件工具。两者需添加文件片段，或接收 Codex 提取后的交接内容。
  • 引用指南文件只会发送指南文字，不会自动读取其引用的 PDF。过去某次工具被拒绝，也不代表当前目录仍不可读；以当前调用卡与实际检查为准。
默认 0，不按总运行时长截断 Codex/Claude Code，仍可手动停止；可设 1～1440 分钟。设置只用于后续调用，不能接回已结束的旧调用。API 连接/空闲等待及工具审批等待保留独立超时。

2. 本机 Agent

扫描不会登录或运行任务。保存时运行一次有超时的 --version，并记录程序哈希。程序更新后需要重新保存确认。CLI 必须先用它自己的登录流程完成账号配置，Hub 不复制登录凭据。

采用本机程序不等于完成兼容性验收。Codex/Claude 使用用户监督模式：原生子 Agent 的审批、用量与停止不能由 Hub 完整控制。
尚未安装？查看官方安装说明

Codex CLI · Claude Code。安装并登录后，重新扫描或手动填写 exe 路径。
