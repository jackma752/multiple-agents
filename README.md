# Agent Hub

<img src="apps/api/agenthub_rt/static/brand/app-icon-256.png" alt="Agent Hub 项目图标" width="96" height="96">

**在一个对话窗口中使用你自己的 Agent，查看模型与用量，并按你批准的规则完成协作任务。**

Agent Hub 连接本机 Codex、Claude Code，以及 DeepSeek API。它保存调用审批、工具决定、上下文、任务依赖与用量记录。账号、订阅和 API 费用仍由各服务提供方管理。

> Windows 桌面版 · 本机服务默认 `127.0.0.1:8080` · 无需预装 Python · 没有安装任何 Agent 也能进入配置页
>
> 当前各通道能力不同。Codex/Claude 的原生子 Agent 不能由 Hub 完整限额或停止，使用前请阅读下方能力表。

## 安装与首次配置

1. 运行 `AgentHub-0.5.1-windows-x64-setup.exe`，按向导安装到当前用户目录。目标系统为 Windows 10/11 x64。
2. 从开始菜单打开 **Agent Hub**。浏览器自动打开本机页面并完成一次配对，无需复制开发令牌。
3. 首次进入 **本机设置**，选择实际的项目文件夹，默认使用只读权限。需要 Codex 修改文件时，可明确选择允许写入。
4. 点击 **扫描常见安装位置**，选择已安装的 CLI；没有发现时，手动填写原生 `.exe` 完整路径和该 Agent 已登录的配置目录。只勾选你要使用的 Agent。
5. DeepSeek 不需要桌面客户端：勾选 API 通道，填写自己的密钥、HTTPS 地址和模型。网络通常保持直连；只有实际使用代理时才填写代理地址。
6. 确认设置，点击 **保存并启用**，再进入对话。保存时仅查询 CLI 版本、记录程序身份，不发送模型请求。

没有某个 Agent 不会影响其他通道或 Hub 启动。扫描只查 PATH 和常见安装位置，不递归扫描磁盘，不读取账号登录文件，不自动下载 Agent。

尚未安装的 CLI 可按官方说明安装并登录：[Codex CLI](https://developers.openai.com/codex/cli/)、[Claude Code](https://code.claude.com/docs/en/setup)。API 密钥由 [DeepSeek 平台](https://platform.deepseek.com/)提供。配置页也提供这些入口。

便携 ZIP 可解压整个 `AgentHub` 文件夹后运行 `AgentHub.exe`；不能单独复制 exe。便携版同样把账号配置和数据保存在当前用户目录，不能把这些用户数据随程序发给别人。

## 功能与操作顺序

下面按功能建立的顺序介绍。从单次受控调用开始，再逐步使用上下文管理和自动协作。

### 1. 创建对话与批准调用

**用途：先看清要发送什么，再决定是否调用 Agent。**

点击 **新会话**，选择 Agent、模型与执行模式，输入任务后发送。发送会生成调用卡；在卡中确认完整内容、模型、工作区、续接对象和预算，再点击 **启动本次调用**。

- **严格模式**：要求适配器具备对应控制能力；不满足的通道会被阻止。
- **用户监督模式**：你知晓当前通道的控制边界，逐次允许调用。它不承诺拦截所有原生子 Agent 或沙箱内操作。
- 对话标题采用简短内容标题，可点 **改名**。时间显示在独立标签中。

拒绝调用不会启动 Agent。审批绑定这次内容和配置，修改设置或策略后可能需要重新审批。

### 2. 流式输出、工具审批与中断

**用途：看见正在做什么，并决定具体工具操作是否可以执行。**

Codex 支持流式文字和工具请求卡。卡上显示命令原文、目录、操作类型和理由。**批准这一次**只对应这一个工具请求；支持范围以卡上按钮为准。

- **拒绝此操作**：不运行这一个请求，Agent 可能继续解释或完成当前回合。
- **中断本轮**：请求 provider 停止回合；只有收到确认才显示已取消。
- **停止本地进程**：停止本机入口进程，不保证远端活动或原生派生进程已停止。
- 消息上的 **复制回复**、调用卡上的 **复制发送内容**可复制对应文本；后者用于核对实际上下文。

### 3. 多 Agent 与手动交接

**用途：把一个 Agent 的结果交给另一个处理。**

在回复旁点 **交给其他 Agent**，再在输入区选择接收 Agent，输入新要求并发送。审批卡会列出所选来源和传递的文字。每个新调用仍须审批。

交接只传选中的结果，不自动共享所有聊天历史。使用 **续接上一轮（原生 thread）**则是让同一个支持续接的 Agent 使用已有线程；审批卡会明确显示线程标识。

### 4. 查看模型、用量与设置预算

**用途：知道哪个 Agent 的哪个模型用了多少，而不仅是一个总数。**

在发送区选择或填写模型及推理强度；支持元数据查询的通道可点 **刷新模型**。调用记录区分请求模型与 provider 返回/线程读回的模型。未知默认模型不会被猜测成某一个模型。

右侧 **用量与预算**按 `Agent → 模型 → Agent 合计`显示，跨 Agent 总计可以选择显示。可切换当前会话与根任务树统计范围，也能为单个模型设置 Token 预算。

- 总预算覆盖根任务树，包括子任务、摘要续聊、审阅和汇总；单模型预算与任务总预算同时检查。
- 单次预算用于启动前预留，计入输入与输出，不是模型中途的硬截断。
- 未知用量不会当成零；未结算预留会保留。多模型、原生子 Agent 的不完整归属会明确标注。
- 严格预算在无法确认可承受调用时阻止启动；软预算会对部分不确定情况给出警告。已知花费达到总预算时仍会阻止。
- 缓存读取量包含在输入统计里，缓存命中率表示缓存读取比例，不代表节省金额。这里主要统计 Token，不是账单金额。

### 5. 文件引用与发送前预览

**用途：只发送与你问题有关的文件片段。**

在 **引用文件**中输入项目内路径，例如 `src/app.py:L10-30`，点击 **添加引用**。带空格的路径可加引号。发送前展开预览，核对文件行号、完整文字、大小和 Token 估算。

文件由 Hub 在发送时读取一次，审批覆盖那次快照。之后编辑磁盘文件不会悄悄改变已审批内容。文件必须位于所选工作区，经过解析路径检查；凭据、版本库内部、依赖、构建输出和数据库等不允许引用。

只接受 UTF-8 文本，每文件最多 1 MB、单片段 40,000 字符、合计 60,000 字符。预览是字符估算，不包含 provider 自带的完整指令、工具定义与原生历史。

### 6. 阶段摘要与压缩续聊

**用途：把目标、约束、进度和问题整理成短上下文，开始下一段工作。**

右侧 **阶段摘要 → 写摘要**可手工填写；**生成摘要草稿**会创建一次需要审批的 Agent 调用，生成后由你检查保存。

- **附带到下一条**：在当前会话的下一次调用带上所选摘要。
- **压缩并继续**：保留原会话，新建携带摘要的会话；原来的预算和根任务累计用量继续沿用。

Hub 的压缩方式是摘要续聊，不会删除旧记录，也不等于在 provider 的原生线程内部自动压缩。Agent 自带的原生压缩由其自身处理。

### 7. 协作计划、依赖与汇总

**用途：让多个子任务按依赖顺序传递结果。**

开启右侧 **协作计划**，可以手写计划，或通过 **请主 Agent 拆分任务**请求规划回复，再点回复上的 **读成协作计划**解析为草稿。检查 Agent、目标和依赖后保存。

例如：任务 1 由 Codex 整理需求，任务 2 由 DeepSeek 翻译并点评任务 1，依赖填写 `1`。只有任务 1 完成并产生最终结果，任务 2 才能分派，并自动附带依赖结果。手动模式下每次分派均单独批准。全部完成后使用 **把结果汇总交给…**。

**读成协作计划**用于解析符合计划格式的回复，不能把任意总结自动变成可执行计划。当前规划调用、草稿确认和执行是分开的步骤。

### 8. 自动执行、失败修复与额度等待

**用途：一次授权一个阶段，让 Hub 在你设定的规则内推进。**

先在对应模式下跑通你要使用的 Agent，再打开 **设置自动执行**。填写阶段目标、完成条件、参与 Agent/模型、计划方式、审阅与汇总、调用上限、最多重试次数，以及明确允许的工具规则，确认后开始。

Hub 根据阶段规则审批调用，记录授权来源。阶段完成后写总结并停止，不会自动开启新阶段。无法解决的错误会形成阻塞总结；修复重试次数由你设置，默认 3 次（首次之外）。暂停和停止均由用户控制。

额度耗尽时，可选择额度恢复后自动继续。调度器保存进度，在 provider 提供恢复时间时按时间等待，否则按间隔检查；后台服务需要保持运行。重启后会恢复等待状态，未知是否执行过的调用不会直接重放。该功能不能代替充值、登录、提升订阅额度或保证固定恢复时间。

### 9. 工作区和本机设置

**用途：换机后重新选择这台机器具备的能力。**

点击页首 **本机设置**修改工作区、启用通道、CLI、登录目录和网络。修改前需要停止开放自动阶段并结束运行中或状态未知的调用。保存会撤销旧的未使用审批。

CLI 更新或被移动时，身份检查会拒绝启动；回设置页重新扫描、确认新程序。采用新版本只确认程序身份，该版本的真实模型、协议及权限表现仍需要在目标机器验证。

## 通道能力

| 功能 | Codex app-server | Claude Code CLI | DeepSeek API |
| --- | --- | --- | --- |
| 当前模式 | 用户监督，严格准入受限 | 用户监督，严格准入受限 | 严格 / 用户监督 |
| 文本输出 | 流式 | CLI 完整结果 | 流式 |
| 模型选择 | 手工填写，支持元数据刷新 | 别名/模型填写 | API 模型填写 |
| 工作区 | 使用选定目录，支持只读/允许写入策略 | cwd 指向工作区，当前原生工具关闭；使用文件引用 | 使用文件引用，无本机工具 |
| 工具审批 | 命令与文件变更请求，按可验证通道处理 | 当前不提供内置工具执行 | 当前不提供本机工具执行 |
| 原生续接 | 支持绑定已有线程 | 不支持 | 不支持 |
| 用量 | provider 报告；原生子 Agent 可能不完整 | provider 报告；多模型可能 partial | provider 报告 |
| 中断/停止 | 以 provider/本机进程确认区分 | 本机进程控制，非原生回合中断 | 不能保证远端取消 |

操作系统文件权限依然有效。Hub 不自动取得管理员权限；也不会因为选择工作区，就自动把整个目录上传给 API 模型。

## 数据与卸载

程序默认安装在 `%LOCALAPPDATA%\Programs\AgentHub`，用户数据独立保存在 `%LOCALAPPDATA%\AgentHub\desktop`。

安装目录可在安装向导中选择；数据目录目前通过环境变量 `AGENT_HUB_DESKTOP_HOME` 自定义，尚无图形化迁移入口。改变数据目录不会自动搬迁旧记录，需要退出 Hub 后迁移并重新启动。工作区则单独在「本机设置」中选择。

| 内容 | 位置/处理 |
| --- | --- |
| 对话、审批、预算、阶段记录 | 本机 SQLite 数据库 |
| 已启用 Agent、程序身份、工作区 | `profile.json` |
| API 密钥 | 用户数据目录内单独的 `credentials` 文件夹；页面不回传 |
| CLI 账号登录 | 仍由你选择的原有 Agent 配置目录保存，Hub 不打包或复制 |
| 模型输入 | 发送给你选择的 Agent/provider；本机保存对话记录以便恢复 |

退出时点击页首 **退出 Hub**。关闭浏览器标签不会自动停止后台；再次点击开始菜单会打开已运行的 Hub 并重新配对。卸载器只删除已发布程序文件，保留对话、密钥和项目；需要彻底清理时，先备份并停止 Hub，再由用户删除自己的数据目录。

分发包不含开发测试、离线桩、历史证据、项目虚拟环境、运行数据库、`.env`、用户聊天、登录文件或 API 密钥。随包提供逐文件清单、校验文件和第三方许可证。当前安装器未做商业代码签名，正式公开发行前需补充签名与独立干净机器验收。

## 常见问题

| 提示 | 怎么处理 |
| --- | --- |
| 找不到 Agent | 未安装也能打开 Hub；安装并登录 CLI 后重新扫描，或填写原生 exe 路径。也可以只启用 API |
| 8080 已被占用 | 关闭之前的 Hub 或为启动器指定其他端口，不需要杀死所有 Python 进程 |
| 需要配对/未登录 | 从开始菜单重新打开 Hub，启动器会为当前用户申请新的单次浏览器配对 |
| 程序身份改变 | 软件更新后重新在设置里确认；不要自动跳过 hash 检查 |
| `file_outside_root` | 引用文件不在当前工作区；选择正确工作区或把确需使用的项目资料放到工作区 |
| `token_budget_exhausted` | 已触及预算，检查统计范围和单模型/总预算后再决定是否调整 |
| `max_agent_invocations` | 当前根任务树调用数已到上限，失败调用也可能计数；调整策略后按页面提示恢复或开启新阶段 |
| 用量未知/partial | provider 未提供完整信息，或涉及原生子 Agent；不是没有花费 |
| 额度不足 | 等待账号额度恢复或调整账号，再使用已授权的恢复流程 |
| API 400 / 网络失败 | 检查 API 地址、模型、密钥和本机代理。错误可能来自 provider，不应反复重试同一配置 |

## 开发与版本维护

源码需要 Python 3.11+；开发者可安装 `pyproject.toml` 的 dev 依赖，运行针对性测试。构建步骤和代码说明见仓库中的 [开发文档.md](开发文档.md)，它不随用户安装包分发。

本版本提供本机离线协议、鉴权和安装验证；在不同机器、新 CLI 版本和真实账号下的行为应以该机器验收结果为准。项目不会携带开发机器的现成登录状态。
