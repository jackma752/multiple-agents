# 科研功能补齐与 ClawsGo 对照

2026-11-02。用户在当前对话要求补全项目并查看 https://app.clawsgo.cn/hosts。基线：main `434e241`，发行 0.7.2。独立分支 `feat/p6-research-completion`。

应用页面只读观察：当前账户尚无主机，入口包括云主机/本地设备、任务、文件、Git、用量、步骤、交付物和子智能体。未创建主机、消耗算力或运行线上研究。官网展示的远程 GPU、浏览器、LaTeX 和图表编辑属于产品展示，本轮不将其当作实测。

先补齐本地科研功能：多来源检索及来源审计；已有成果的可移植导出/打包；实际实验记录和指标比较。保留全文补充、数学讲解和根任务授权/预算。远程主机需要用户确认范围，不能把连接 SSH 和提供云基础设施混为一谈。

公共契约先行：允许 arXiv/OpenAlex/Crossref/Semantic Scholar 来源；默认仍 arXiv，旧请求与规则哈希保持。外部来源给出的 PDF 地址只有用户明确批准公网全文下载后才可自动访问；选择更多来源不自动放宽文件/网络权限。所有来源的失败、空结果与部分成功应保留。

来源实现独立编写，使用各来源官方 HTTP 文档；不复制 ClawsGo 页面、品牌、脚本或模拟科研结论。实验功能只接受明确记录的真实/演示数据，不能把合成模板成功写成目标论文复现成功；不自动执行未经批准的生成代码。

验证：来源结构与跨源去重、单源失败、资源门禁/旧哈希、端到端补充阅读、导出内容和包校验、实验记录隔离/版本/数值与比较。使用隔离数据和离线夹具；真实来源可用性、实际模型质量分别记录，不操作现有任务或凭据。
