## 更新与使用

1. 点击当前页“退出 Hub”，然后运行新 setup，选择原安装目录 `E:\multiple-agent\AgentHub` 覆盖安装，不先卸载，不删除数据。
2. 从开始菜单重新打开，在本机设置确认“单次执行时限”是 0。旧明确设置可自行修改，保存前需停止开放阶段并处理未知调用。
3. 对已核实结束的旧超时调用，点“登记超时调用已结束”并确认；现有文件保留，产物仍需检查。
4. 当前旧任务的明确累计限额不会自动清空；需要不限制累计次数时，在控制台把总调用数/子 Agent 总量设为 0，并重新授权阶段从剩余步骤继续。不要重做已有文件。
