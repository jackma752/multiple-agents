## 已实现

- 请求选择快速综述、读懂与推导、研究方案、论文项目。旧请求新增默认字段不进入序列化，旧哈希与恢复路径不变；新页面默认论文项目、1 篇核心论文、1 轮补读/局部修复。核心论文按持久化纳入顺序选取，其余只做关联阅读；预检展示预计调用与总预算，不提高旧任务限额。
- 核心方法从定义、定理、证明、算法和附录等结构锚点及邻块提取上下文，每轮有字符上限。教学单元包含问题、直观说明、预备知识、符号/定义域、设定、假设与用途、结果、至少两步 LaTeX 推导、理由/依赖、例子和下一项学习任务。来源与补充重建分开，位置由实际 chunk/PDF 页计算。
- “完整”结果必须通过字段与依赖结构校验，关键问题/设定/假设/结果需来源；引文包含只证明来源位置，不证明语义和数学正确。资料不足可保留部分单元与缺口，不要求伪造全部结构以通过校验。
- 审阅接收数学结构和实际原文片段。材料问题请求页或证明锚点，先补读未读材料；找不到新材料就不为同一资料继续重写。数学/引用问题按稳定单元 ID 局部替换，必要时补齐缺失单元；未改内容保留，复查变化与依赖。文风小问题不触发修复；授权轮数与预算仍生效。
- 来源定位、数学模型核查、研究候选验证、语言维度分别显示。“讲解模型核查完成”不能解释为形式化证明或方案新颖性通过。候选保持 unverified，包含基线、具体改动、证明/算法路线、最小验证、成功/失败条件、知识准备和第一周任务。
- 新增教学界面、公式渲染与 `study.md`、`research-plan.md`、结构化报告；保留 review.md 下载兼容。来源审计折叠，具体缺口在讲解旁显示，各模型步骤显示实际用量。
- 论文项目选择方案、保存证明/实现/实验或反例/实际结果/草稿/投稿/返修笔记。新增版本记录表，expected_version 防止另一窗口覆盖；保存与重新导出均不调用模型。下载文件是最新快照，历史笔记版本保留在数据库。
- “追问这一步”和“指导下一步写作”组装选中步骤及依赖、来源、选定候选和已有项目，通过原 submit_turn 生成 pending 审批。没有直接启动 Agent，不重新检索整个主题；后续调用仍受原根任务总预算与限额影响。

## 仍需实际验收的能力

- 真实模型能否对具体论文给出正确且足够详细的数学推导，尚未由本轮真实调用验证；本轮真实调用为 0。第一项科学质量验收应是一篇公开核心论文的逐式人工核对，不能把下面的离线流程通过视为已经验收。
- 当前使用 PDF 文本解析，未增加 OCR、版面数学识别或外部 LaTeX 源码下载。公式损坏时只能明确请求补充/指出缺口，不能承诺自动恢复。结构检索不是语义检索，页/锚点无法定位时会保留缺口。
- 研究候选未做自动新颖性检索、自动程序实验或形式化证明。论文项目提供持续记录和可审批的写作指导，不会自动产生真实实验数据、完整原创论文或提交期刊。选定目标后需查其官方要求。
- 现阶段有总 Token 预算、按步骤用量和调用估算；没有新增四套独立阶段 Token 硬预算，也没有证明在真实任务上节省某个固定比例。不是无限增加轮数来追 PASS。

## 实际验证

- 第一轮受影响回归：118 passed in 58.06s（论文、会话页、自动执行与策略）。最终论文指导专项 11 passed in 4.00s；后续最终论文全范围加旧探针失败用例：84 passed in 45.43s，覆盖新结构、精确来源、局部替换、材料补读、缺证明不重写、暂停重启、预算零启动、项目版本保存和追问待审批。
- 阶段完整集曾运行：1855 passed / 2 failed in 4548.35s。其中新状态预期在运行期间变更，导致该轮混用了调整前后的预期；旧 S6-3 recall-failed 的组合运行返回 FAIL 而不是预期 INCONCLUSIVE。最终定向复核 84 项含两者均通过。没有再次长时间全量/压力测试，不声称最终提交全量全绿。
- 离线 Headless Edge：默认项目路径、公式/本地字体、项目编辑保存、轮询不丢输入、窄屏、无外部资源请求通过，无 JS 错误。数据是自建模拟夹具，不含用户报告或真实模型输出。
- 算例验证经典迭代 x_(n+1)=(x_n+1)/2 的前 8 步与几何尾项，不能据此证明任意生成推导正确。
