# P5：Windows 安装与换机

授权：2026-10-27，用户要求本地合并、安装包、工作区访问、无凭据分发及使用/维护文档。

## 实现顺序

1. 整合已有模型、协作恢复、DeepSeek 和页面修复；保留原有记录和标签。
2. 安装版独立入口，用户数据放在 LocalAppData；首次启动没有任何已启用 Agent。
3. 配置页扫描常见安装位置，也能手动指定 exe；用户确认后记录路径、哈希、版本。缺少 Agent 不影响 Hub。
4. DeepSeek 按 API 通道配置，不要求安装桌面程序；密钥保存在用户目录，不进入包。
5. 工作区由用户选择，目录和权限进入调用快照和审批；Codex 使用该 cwd。DeepSeek/当前 Claude 受限通道通过文件引用读取内容，不声称具备原生编辑工具。
6. 每次启动检查已采用二进制，更新后拒绝并提示重新采用。采用只确认本机程序身份，不能证明新版本协议兼容或严格子 Agent 隔离。
7. 安装版生成随机本机授权，单次配对票据换浏览器会话；源代码开发模式保留测试认证，安装版不接受固定开发令牌。
8. 自包含程序和按用户安装器，不依赖目标机 Python。打包采用文件白名单，不包含测试、开发环境、运行记录、登录材料或 Agent 本体。
9. 编写 README 和本地开发文档，执行针对性测试、一次阶段全量、干净数据目录启动与安装包检查，再本地合并，不推送。

## 边界

- 扫描不是全盘递归，不读取登录文件。采用程序时仅运行有超时的版本查询，不发送模型请求。
- 代理默认直连，可显式设置。使用系统/内置证书验证，不关闭 TLS 检查。
- Codex/Claude 仍是用户监督通道；原生子 Agent 不保证能由 Hub 限额或停止。
- 新机器真实模型和原生读写行为必须在该机器配置账号后验收；本次仅本地协议测试与安装检查。
- 自动执行规则、配额、预算与审批后端约束必须保持。
