## 实际验证

- 完整测试集 1730 项通过，1 项因开发认证拆分导致的旧源码位置断言失败。该断言改为环境认证行为检查后相关 35 项通过；重开入口增加后的相关检查 36 项通过。完整细节见 [P5 验证记录](p5-distribution.md)。未声称同一轮完整集全绿。
- 首次无 Agent 启动进入设置；单次本机配对；仅启用合成 API 配置；密钥字段保存后清空；模型选择器和工作区待审批卡正常；脚本错误 0。
- 最终安装器实际安装 exit 0，安装文件哈希与包内程序相同。再次打开 exit 0，产生新单次票据，原进程保留，未启动第二个 Worker。
- 安装程序退出后私有临时控制文件移除。卸载 exit 0；程序、注册项、快捷方式移除，额外用户文件和独立数据库保留。
- 逐个校验 MANIFEST 中 134 个文件的大小和 SHA-256，并读取真正的 PYZ 内嵌目录，检查 937 个模块。pytest、tests、Mock、app-server 桩和 dev_auth 模块缺席。
- ZIP 不含 `.git`、虚拟环境、tests、var、evidence、auth.json、credentials.json、profile.json 或 instance.json；分发 HTML 不含固定开发令牌。
- 模型真实请求为 **0**。现有用户的 8080 服务没有操作；测试使用独立数据目录和 18195–18198 端口，测试实例均已停止。
