累计 **9 次真实调用**，输入 **24,322** / 输出 **28,544**，合计 **52,866 Token**；用量记录完整，其中推理 Token 18,187 已包含在输出中，不重复相加。最初计划 50,000；最后一轮阅读实耗 12,200，超过 8,000 预留，累计超出计划 2,866。现有预算约束启动前预留与后续准入，不能在 provider 达到 N Token 时硬停止。超额已记录，此后不再追加模型请求。部分未启动的草稿也出现在步骤 calls 中，不能把它们当成真实调用。

**完整多源研究和合格数学讲解未通过本次在线验收。** 不声称安装版在线科研已成熟，也不以离线测试数量替代科研质量。

## 本轮修复

1. 论文 API/UI 增加 `token_budget_per_call`，已有 Policy 类型不变。总预算缺预留、预留超过总预算时预检阻止，新任务保存预留，接续保留预留；剩余预算不够下一次预留时拒绝接续。无预算旧请求与已批准资源哈希保持。
2. 筛选缺项错误给出具体论文 ID，来源跨度错误给出单元及分块 ID。引用必须匹配原文的要求不放宽，模型原始错误和原步骤保留。新反馈尚未追加真实模型验证。
3. 全部查询成功但无条目时，arXiv 只允许一次首词组兜底查询，保持年份/来源/篇数，审计保留原查询及 broader 标识。HTTP 失败不触发；不循环扩搜，不新增规划调用，旧成功步骤键不改。该兜底已在真实网络找回 RAGAS。
4. 新增明确选择才执行的 `tools/probes/p6_online.py`。不复制或输出密钥；运行时通过现有通道读取宿主凭据。独立状态、真实/模拟明确区分；不完整研究返回非零验收状态，不能因有 JSON 文件或空导出就判通过。

对应 [需求与公共接口约束](issue-p6-online-080.md)。本轮只实测 DeepSeek 严格通道；Codex/Claude 严格通道未验证，传输优化另按用户新增要求继续。
