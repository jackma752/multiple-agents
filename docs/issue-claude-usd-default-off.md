# Claude 单次美元上限默认关闭（2026-11-05）

用户明确要求将导致论文步骤中断的单次美元预算功能默认关闭。前置只读诊断确认：两条 Claude 启动路径均固定传入 `--max-budget-usd 1.00`，真实失败记录返回 `error_max_budget_usd`。该限制与 Hub 用户设置的 Token 总预算不是同一项。

## 实施范围

- 用户监督和严格文件工具路径均不再默认传入 `--max-budget-usd`，不以 0 或更大金额替换。
- 保留 Hub 的 Token 预算、调用数/重试/时限、阶段授权、工具审批及原生子任务约束。不自动重跑旧失败任务或改动阶段规则。
- 实际适配器调用绑定增加金额配置修订标识；旧审批与旧待启动调用不能在未重新授权的情况下使用新启动配置。模拟适配器身份保持不变。
- 同步当前能力文档与零模型探针的默认参数清单，历史测试中的 1 美元记录保留为当时行为。
- 在前一轮空正文修复分支之上独立开发，以便形成包含两项修复的候选；本次没有新增付费模型调用授权。

## 验证计划

核对实际监督/严格 argv 均无美元限额；验证原有权限标志和故障拒绝、旧绑定拒绝，以及 Token 预算不足时不启动。执行相关适配器、策略、预算和研究回归。随后构建并验收安装候选；只有确认本机无运行/未知调用和活动阶段后才更换程序，不自动暂停用户阶段。

## 源码验证

`tests/adapters/test_claude_code_adapter.py`、Claude 门禁、原生工具、HTTP 预算准入、论文预算、纯预算规则、Claude 零模型探针和原生预检共 **192 passed in 36.54s**。覆盖实际启动参数未传美元限额、旧金额配置绑定拒绝且启动 0 次、权限/Token 门禁保持。
